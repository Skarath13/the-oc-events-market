# Photo replacement plan

Remaining stock images are licensed editorial context only, not portfolio proof. Replace them with
owner-controlled or written-permission media before presenting any surface as documented client
work.

## Current partial replacement

The homepage gateway places the packaged favors with Weddings, dessert finishing with Showers, the
50th backdrop with Milestones, the first-birthday backdrop with Kids’ Parties, and Ivone’s setup clip
on the Corporate and Brand Events card. These are presentation placements, not verified source-event
classifications. The same stills lead the corresponding event pages. Ivone’s confirmed portrait
appears on About. The Pexels homepage hero, Unsplash About hero, corporate event still, network
imagery, venue imagery, and service/planning imagery remain licensed editorial stock until matching
rights-cleared event media is available. Portrait balloon images use portrait frames so the work is
visible without an aggressive landscape crop.

## Replacement order

1. **Hero — critical.** Supply one signature real event with separate landscape and portrait crops.
   Preserve clear text-safe areas and provide photographer and vendor credit requirements.
2. **Remaining event imagery — high.** Supply a rights-cleared corporate or brand event image and
   additional category-specific details. Each image must belong to the matching event type.
3. **Celebration stories — high.** Supply complete galleries and confirmed project facts before
   enabling `showCelebrationStories`.
4. **Planning proof — medium.** Add legitimate behind-the-scenes images: walkthroughs, floor plans,
   timeline review, installation, vendor check-in, or detail styling. Do not expose private client
   data in documents or screens.
5. **About/team — medium.** Add a high-resolution working portrait if a wider About composition is
   desired. The current confirmed Ivone image remains suitable for the existing portrait frame.
6. **Social and icons — critical for launch.** Replace the temporary Open Graph image and favicon
   set after the original transparent logo is received.

## Per-image intake

Record the original file, creator, copyright owner, written usage permission, event name, event type,
venue, city, alt-text context, vendor-credit wording, consent limits, and expiration or takedown
terms. Keep model releases where recognizable people are central. Do not infer consent from an
Instagram post.

After replacement, remove the unused stock source from `src/assets/images`, update
`IMAGE_LICENSES.md`, verify all crops at the six required viewports, and rerun `pnpm verify`.
